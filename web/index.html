How it works

  1. Search — your question is matched by meaning and by keywords.
  2. Select — only clearly relevant chunks pass; the best ones are kept.
  3. Answer — the model answers from those sources only and cites them.

If nothing in the documents is related, you'll be told so instead of getting a guess.
